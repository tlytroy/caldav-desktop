## 2. 目标与非目标

### 目标

1. 数据可靠：读取失败不静默清空；原子写；全写路径统一；崩溃/并发可复现验证。
2. 数据可恢复：备份可预览、可校验、可回滚；恢复后同步/提醒状态一致。
3. 安全：token 必须；API 全部受保护；Electron 无感；Docker 升级有自救路径。
4. 可观测：一页看清同步状态与冲突（不联网加载）。
5. 本地优先：仅本地模式承诺离线完整可用；直连模式有明确错误提示。

### 非目标

- 多用户、账号密码、OAuth、共享日历
- CalDAV 墓碑删除传播、VTODO
- 重复事件例外模型、拖拽改期（v0.4）
- schema 迁移框架；自动改写用户文件
- 原生移动端、AI Agent、插件市场、Git 同步
- 限流（v0.3.1）、WebDAV 自动同步（v0.3.1）

### M2 · 数据核心（6–8 人日；本期最大）

#### 2.1 读取失败必须可见

- `readWorkspace` 在「文件存在但读失败/解析异常」时 **throw**（不再返回空 items）；
- API 返回 500 + 可读错误；**绝不触发写**；
- 文件不存在仍返回空集合（首次启动合法）。

#### 2.2 唯一写入口

- `writeWorkspace` 改为私有；导出 `mutateWorkspace(fn)`：
  - 获取锁 → 重新读取 → `fn` 修改 → 校验 → 原子写 → 释放；
- 迁移全部 workspace 写入：
  - `routes/workspace.ts` 5 处、`caldav-sync.ts` pull、`routes/webdav.ts` pull/merge；
- 状态文件（caldav/webdav/reminder）与 config 写入也走原子写（不加 workspace 锁）；
- 禁用 `md-bridge` 任意路径写、`kanban.ts` 写（M1 下线）。

#### 2.3 原子写与文件系统自检

- 同目录 `workspace.md.tmp.<pid>` → `fsync(fd)` → `close` → `rename`；
- POSIX 下 `fsync(dir)` best-effort；
- Windows rename EPERM/EBUSY：5 次重试（100/200/400/800/1600ms），仍失败**报错**；
- 启动自检：写 tmp → fsync → rename → fsync dir；失败默认**拒绝启动**，
  `ALLOW_UNSAFE_FS=1` 才允许继续并强告警；
- 只清理本进程 pid 的陈旧 tmp（启动时清理 >1h 的）。
- 文档：数据目录必须在本地 ext4/NTFS/ Docker volume；SMB/NFS 不保证原子性。

#### 2.4 锁与同步改造

- `withWorkspaceLock`：进程内 Promise 队列；10s 超时可取消；禁止重入；
- **网络 IO 在锁外**；CalDAV pull：先拉取远端 → 锁内重读 + 合并 + 写；
- CalDAV push：锁内取快照 + 指纹 → 锁外 PUT → 锁内复核指纹：
  - 指纹变化 → 标记「需再同步」，不覆盖远端；
  - 412 → 409 冲突；
- WebDAV merge：先下载 → 锁内基于最新本地重算 merge → 锁外 PUT（If-Match）→
  成功后锁内写本地；PUT 失败则本地不动；承认跨网络无法原子。
- 恢复、备份、同步共用同一把锁。

#### 2.5 不变量与 round-trip

- 写入前校验：id 唯一、parent 存在、无环、end>start、remind 格式；
- 解析保留：
  - 未知 `- key: value`（`item.extra`，含位置）；
  - 未知块（文件级/条目级）；
  - frontmatter 原样；
- 修复：title/description 含换行时的破坏；frontmatter 被丢弃；
- 序列化幂等：`serialize → parse → serialize` 结果稳定；
- 顺序仍按现有排序规范化（不承诺字节级保序，测试断言「集合 + 幂等」）。

#### 2.6 测试

- 并发 50 POST + 同时 CalDAV pull；
- 同 item `title`/`due` 并发 → 两字段都保留；
- 故障注入：`WORKSPACE_CRASH_AFTER_TMP=1` 在 tmp 写完后 `process.exit(1)`；
- 读取失败（chmod 000 / mock throw）→ 500 且文件不变；
- round-trip 未知字段/块/frontmatter + 幂等。

验收：见第 6 节。

### M3 · 备份与恢复（3–3.5 人日）

1. API：
   - `GET /api/workspace/backups`：文件名、时间、大小、条目数、是否 pinned；
   - `POST /api/workspace/backups/preview`：basename 校验（禁止 `..`/绝对路径/realpath 越界）；
     复制目标到 `.workspace-backups/.pinned/<sha256>.md`，返回 diff + sha256；
   - `POST /api/workspace/backups/restore`：`{ file, sha256, confirm: true }`；
2. 恢复流程：
   - 设置 `maintenance`（调度器跳过）；
   - 停止 CalDAV 自动同步 + 等待 inFlight 结束（epoch 丢弃旧结果，超时 10s）；
   - 获取锁；
   - 校验 sha256；备份当前到 `pre-restore-<ts>.md`（独立目录，不参与轮转）；
   - 原子写入；
   - 重置 CalDAV/WebDAV etag 状态；
   - 提醒 sent：按 `id|remindAt` 保留仍存在的；清理其余；
   - 释放锁，恢复调度器；**自动同步保持暂停**，用户显式选择方向；
   - 返回 diff 报告。
3. 保留策略：
   - 自动备份最多 20 份 / 合计 50MB，超出按时间删除；
   - `pre-restore` 最多 5 份；
   - pinned 预览 24h 后清理。
4. UI（设置 → 数据）：
   - 备份列表（时间/大小/条目数）、预览（+新增 / -删除 / ~修改 + 前 20 标题）、恢复；
   - 二次确认文案：「恢复只改本地文件，云端/手机不会自动变；下次同步可能冲突」；
   - 显示版本、数据文件绝对路径、备份数量、`/health` 状态；
   - 首次打开 v0.3 的令牌页兼作「升级须知 + 导出备份」。
5. 测试：
   - 预览期间轮转删除原文件 → pinned 仍可恢复；
   - sha 不匹配 → 409；
   - 恢复时 inFlight 同步被 epoch 丢弃且不写；
   - 恢复后 sent 保留/清理正确；第一次同步不自动跑。

### M4 · 安全接入（4–5 人日）

#### 4.1 token 生命周期

- 解析顺序：`API_TOKEN` env → `API_TOKEN_FILE`（默认 `dirname(workspace)/api-token.txt`）→ 生成 32 字节 hex 并写文件（0600）；
- 启动日志只打印**路径**，不打印 token；
- 无 token 不退出：服务启动，`/health` 与静态可访问，`/api` 401；
- token 删除/修改后重启即轮换；浏览器/PWA 需重新输入；
- Electron：主进程生成 token（每次启动），传 server env；同时写 userData 文件兜底；
- Docker：token 文件在 `/data`，宿主机可直接 `cat data/api-token.txt`；compose **不**用 `:?` 强制。

#### 4.2 中间件与 CORS

- `createApp` 顺序（最终）：
  1. `cors`（OPTIONS 由它结束）；
  2. `/health`；
  3. static；
  4. `app.use("/api", auth)`；
  5. `express.json({ limit: "1mb" })`；
  6. 所有 API 路由；
  7. SPA fallback。
- auth：`Authorization: Bearer`；SHA-256 + `timingSafeEqual`；统一 401 `{ error: "未授权" }`；
- 禁止 `startsWith("/api/")` 判断；用挂载路径；
- CORS：默认同源；`CORS_ORIGINS` 白名单；dev 允许 5173；`Vary: Origin`；
  `null` origin **不再支持**（Electron 走本地 HTTP）；
- `TRUST_PROXY_HOPS`（默认 0）：只影响 `req.ip`/日志；>0 启动强告警「勿直暴端口」；
- **不限流**（v0.3.1），但 token 必须 256-bit；日志脱敏。

#### 4.3 Electron（只保留一条路径）

- 主进程：随机端口 + `HOST=127.0.0.1` + `STATIC_DIR`（打包的 renderer）；
- 等待 `/health` 成功后再 `loadURL("http://127.0.0.1:<port>/")`；
- preload 在页面脚本前**同步**注入：`window.__API_BASE__=""`、`window.__API_TOKEN__`;
- 关闭 `file://` 路径、`null` origin、固定 3001；
- token 同时写 userData `api-token.txt`，关于页可复制（注入失败时自救）。

#### 4.4 前端

- API 客户端统一从 `window.__API_TOKEN__` 或 localStorage 取 token；
- 401 全局拦截 → 令牌页（含 Docker 用户指引：`data/api-token.txt`）；
- 令牌页兼作升级须知；提供「导出备份」；
- 所有 fetch/axios 统一：`api/workspace`、`caldav-sync`、`webdav`、`notifications`、`config`、`nlp`、`framework/plugins`；
- **ICS 导出**改为带 token 的 fetch → Blob 下载（`window.open` 不再用于 API）；
- plugin manifest fetch 加 Authorization；
- 设置/关于显示版本、数据路径、备份数。

#### 4.5 Docker / 文档

- compose 不强制非空；启动后 token 写 `/data/api-token.txt`；
- DEPLOYMENT：迁移指南（备份 data/、拉新镜像、读 token、输入）、忘记 token、轮换、反代透传 Authorization；
- 删除「后端没有内置登录」旧文案；
- 保留上一个镜像 tag，降级安全（workspace 格式未变）。

#### 4.6 测试

- 401/200；`OPTIONS`（无 Authorization）→ 204 + ACAO/ACAH；
- `app.use("/api")` 大小写/路径绕过测试（`/API/...` 同样 401）；
- `TRUST_PROXY_HOPS` 单测：hops=0 忽略 XFF；hops>0 启动告警；
- 静态资源与 `/health` 公开；`/api` 全 401；
- Electron 手工清单（非 CI 门禁）：无 token 显示令牌页、注入后正常、端口随机；
- ICS 下载带 token；plugin manifest 带 token。

## 6. 验收（可执行）

1. **无 token**：`/api/workspace/items` → 401；`/health` → 200；token 文件存在（自动生成时）。
2. **OPTIONS**：无 Authorization 的 `OPTIONS /api/workspace/items` → 204 + ACAO/ACAH；GET 无 token → 401。
3. **路径绕过**：`/API/workspace/items`、`/api//workspace/items` 无 token → 401。
4. **代理**：单测 `req.ip`：hops=0 时伪造 XFF 无效；hops>0 启动告警；认证不依赖 IP。
5. **读取失败**：chmod 000 或 mock 抛错 → API 500，文件内容不变，无写入。
6. **并发创建**：50 POST → 50 条，无重复 id。
7. **并发字段**：同 item 的 title/due 并发 → 两字段保留。
8. **并发同步**：50 请求 + CalDAV pull → 条目数正确，无解析错误。
9. **崩溃**：`WORKSPACE_CRASH_AFTER_TMP=1` 写 tmp 后 exit → 重启文件可解析，tmp 清理。
10. **round-trip**：未知字段/块/frontmatter 保留；serialize→parse→serialize 幂等。
11. **恢复**：预览 sha 固定；恢复后自动同步暂停、sent 按 key 保留、首次不自动跑；inFlight 被丢弃。
12. **同步中心**：无网络时 overview 秒回；未配置/失败/冲突显示正确。
13. **Electron**（手工清单）：随机端口、等 health、token 注入、`file://` 不再使用。
14. **Docker**：老数据 + 空 API_TOKEN 启动 → 生成 token 文件；页面提示输入；读写正常。
15. **本地模式断网**：日历/任务/应用内提醒可用。
16. **ICS 导出**：带 token 的 fetch 下载成功；插件列表带 token 正常加载。
