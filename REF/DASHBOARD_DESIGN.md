# 工作台页面 (Dashboard) 设计文档

## 概述

工作台是用户登录后的首页，旨在提供一个统一的入口，整合各模块的概览信息，让用户能够快速了解当前状态并执行常用操作。

## 组件树

```

├── SearchHeader          # 全局搜索与用户头像
├── WelcomeCard           # 欢迎信息 + 今日概览

│   ├── ModuleCard        # 活跃模块卡片
```

## 状态管理

### Store 数据依赖

| 数据         | 来源 Store             | 用途         |
| ------------ | ---------------------- | ------------ |
| 今日事件列表 | `calendarStore.events` | 今日日程展示 |
| 同步状态     | `syncStore.status`     | 同步状态指示 |
| 上次同步时间 | `syncStore.lastSync`   | 时间显示     |
| 主题偏好     | `themeStore.theme`     | 主题适配     |

### 本地 UI 状态

| 状态           | 类型      | 默认值  | 说明         |
| -------------- | --------- | ------- | ------------ |
| `searchQuery`  | `string`  | `''`    | 全局搜索输入 |
| `isRefreshing` | `boolean` | `false` | 手动刷新中   |

## 响应式布局

| 断点       | 布局       | 说明                               |
| ---------- | ---------- | ---------------------------------- |
| < 640px    | 单列堆叠   | 移动端：今日日程和快速操作上下排列 |
| 640-1024px | 双列自适应 | 平板：保持双列但卡片紧凑           |
| > 1024px   | 双列固定   | 桌面：展示完整信息                 |

## 占位模块处理

未开发的模块在工作台中以灰色卡片展示，点击时提示"功能开发中"：

```tsx
// 占位模块卡片组件
function PlaceholderModuleCard({ module }: { module: ModuleInfo }) {
  return (
    <div className="opacity-50 cursor-not-allowed">
      <LockIcon />
      <span>{module.name}</span>
      <span className="text-xs text-gray-400">即将到来</span>
    </div>
  );
}
```

## 实现优先级

### P0 (MVP 必需)

- WelcomeCard + 今日日程概览
- QuickActions (新建事件 + 设置)
- ModuleGrid (跳转到各模块)
- SyncStatusCard (只读状态)

### P1 (增强体验)

- 全局搜索
- 手动同步按钮
- 占位模块灰色展示

### P2 (未来迭代)

- 个性化问候（根据时段/节假日）
- 天气/日历小部件
- 可自定义的工作台布局（拖拽卡片）
